# TrackMan 45分練習記録アプリ（GolfExec）

TrackMan室内レンジでの45分練習を、毎回同じ8ブロックの流れで実施し、1球ごとに「成功／許容／致命的」をワンタップで記録するスマートフォン向けWebアプリです。要件は `TrackMan_45分練習記録アプリ_要件仕様.md` に従っています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面一式（ホーム／練習実行／ブロック結果／練習終了／履歴・記録修正／分析／設定） |
| `practice-core.js` | 練習メニュー定義と判定・集計ロジック（純関数。DOM・保存先に依存しない） |
| `store.js` | データ層（初版：この端末の LocalStorage。Firebase版は同じインターフェースで差し替え予定） |
| `manifest.json` / `sw.js` | PWA（ホーム画面に追加・オフライン起動） |
| `test.html` | `practice-core.js` の単体テスト（ブラウザで開くだけで実行） |

## セットアップ

ビルド不要の静的ファイルです。

1. フォルダ一式を GitHub Pages などの HTTPS サーバーに置く（PWA と通知はHTTPSまたはlocalhostで動作）
2. スマートフォンで `index.html` を開き、ブラウザのメニューから「ホーム画面に追加」

ローカル確認：

```bash
cd GolfExec
python -m http.server 8793
# http://127.0.0.1:8793/index.html  /  http://127.0.0.1:8793/test.html
```

## 使い方

1. ホームの「今日の45分練習を開始」を押す（2タップ以内で記録開始）
2. 上部に全体残り時間・ブロック残り時間、中央に練習方法・クラブ・目標距離・意識するポイントが出る
3. 1球ごとに **成功(2)／許容(1)／致命的(0)** の大型ボタンを押す。必要な球だけ「数値を追加」で Carry・Side・Club Path・Face to Path・Club Speed を入力できる
4. 時間になると音・振動・画面表示で次のブロックを案内。「次へ」でブロック結果（球数・合否・ミス傾向・メモ）を確認して次のブロックへ
5. 本番4球テスト後に練習終了画面（総合達成率・各ブロック合否・テスト点数・体調・疲労度）で保存
6. 履歴（日別カレンダー）・分析（7日／30日／全期間のブロック別達成率、7I致命的ミス率、110〜135yd目標円内率、DR生存率・OB想定率、30〜90ydグリーン相当率、テスト点数推移）を確認
7. 記録の修正：履歴から記録を開き、球をタップして ○→△→× を変更。集計・グラフも更新される

中断した場合は、ホームの「練習を再開する」で同じブロック・残り時間から再開できます（タイマーは時刻差分から復元するので、画面スリープ中も正しく進みます）。

## 判定ロジック（practice-core.js）

- ブロック合否：成功≧minSuccess かつ（成功＋許容）≧minAlive かつ 致命的≦maxFatal（設定画面で変更可）
- 本番4球テスト：合計6点以上 かつ 0点なし で合格（最大8点）
- 総合達成率＝獲得点数÷最大点数×100、生存率＝（成功＋許容）÷球数、致命的ミス率＝評価0÷球数
- 目標距離：110〜135ydは各距離2球→残り8球ランダム、30〜90ydは各距離2球を同じ距離が連続しない順で

## 設定

利き手、単位（yd/m）、音・振動、練習場所、クラブ一覧と平均Carry、各ブロックの時間・球数・合格基準、目標距離、CSV出力、バックアップ（JSON）の保存と復元。
