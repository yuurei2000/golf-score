# ゴルフビンゴ（16 名・全員違うカード）

ラウンド中の出来事（フェアウェイキープ・パー・寄せワン・バーディー など）が 5×5 のマスに並んだビンゴ。できたらマスを開けて、縦・横・斜めをそろえる。静的 HTML だけで動く（サーバー・ログイン不要）。

## 使い方

1. 幹事が `index.html` を開く。ゲームコード（5 文字）が出る。コンペごとに「新しく作り直す」。
2. 参加者 No.1〜16 に「カード」の URL か QR を渡す（「全員の URL を写す」で LINE などに貼れる）。紙なら「全員のカードを印刷」（A4 に 4 枚 × 4 ページ）。
3. 各自、自分のカードでマスをタップ → 何番ホールかを選ぶ。印はその端末に残る。
4. 上がりの後、「結果を写す」で見せ合い、順位を決める（ビンゴの本数 → リーチの数 → 開いたマスの数）。

## 16 枚を全員別にする作り方

- 出来事は 104 種（やさしい 45・ふつう 37・むずかしい 22）。1 枚に 10・9・5 個ずつ、真ん中は FREE。
- 1 枚ずつ、これまでの札で使われた回数が少ない出来事から選び（120 通り試して、前の札と重なる数がいちばん少ない組を採る）、並べ方は 2 マスの入れ替えで前の札と重ならないようにする。
- 結果（コード 5 種で確かめた）：同じカード 0 組・同じ位置に同じ出来事 0 組・同じ列に 3 個以上同じ出来事 0 組・2 枚で重なる出来事は平均 4.4 個／最大 7 個（24 個中）。
- どの列もやさしいが 1 個以上・むずかしいは 2 個まで（どの列にもそろう見込みがある）。
- 同じゲームコードなら、どの端末でも同じ 16 枚になる（乱数の種がコード）。

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | 画面（幹事・各自のカード・印刷） |
| bingo-core.js | 画面に依存しない関数（出来事の一覧・カードの作成・違いの点検・ビンゴの判定） |
| test.html | bingo-core の試験（59 件） |

URL：幹事 `index.html#g=コード`、各自 `index.html#g=コード&p=番号`、印刷の見本 `index.html#g=コード&print=1`。名前は URL に入れず、入れた端末にだけ残す。
