# ゴルフビンゴ（16 名・全員違うカード）

ラウンド中の出来事（フェアウェイキープ・パー・寄せワン・バーディー など）が 5×5 のマスに並んだビンゴ。できたらマスを開けて、縦・横・斜めをそろえる。静的 HTML だけで動く（サーバー・ログイン不要）。

## 使い方

1. 幹事が `index.html` を開く（幹事の画面）。ゲームコード（5 文字）が出る。コンペごとに「新しく作り直す」。
2. 「参加の URL（全員共通）」の URL か QR を全員に送る。
3. 各自、名前を入れて「参加する」→ 空いている番号（1〜16）のカードがランダムに当たる。抽選は Firestore のトランザクションで行うので、同時に押しても重ならない。同じ端末か同じ名前で入り直すと、前の番号に戻る。17 人目は満員。
4. ラウンド中、マスをタップ → 何番ホールかを選ぶ。印は端末と Firestore に残り、幹事の画面に参加状況と順位（ビンゴの本数 → リーチの数 → 開いたマスの数）が自動で出る。
5. 紙なら「全員のカードを印刷」（A4 に 4 枚 × 4 ページ）。参加を使わずに番号を決めて配るときは「番号ごとのカードの URL」。

Firestore（GolfMatch と同じ golfmatch-323b1）につながらないときは、その端末だけで番号を引く（ほかの人と重なることがある。画面に注意を出す）。

## Firestore のルール

`firestore.rules` は GolfMatch のルールに `bingo` を足した全文。Firebase コンソールの Firestore →「ルール」にこの全文を貼って「公開」する（GolfMatch の分も入っているので、そのまま置き換えてよい）。

- `bingo/{コード}`：`seats`（番号 → 名前・端末の鍵）
- `bingo/{コード}/cards/{番号}`：名前・印・ビンゴ・リーチ・マス数

## 16 枚を全員別にする作り方

- 出来事は 104 種（やさしい 45・ふつう 37・むずかしい 22）。1 枚に 10・9・5 個ずつ、真ん中は FREE。
- 1 枚ずつ、これまでの札で使われた回数が少ない出来事から選び（120 通り試して、前の札と重なる数がいちばん少ない組を採る）、並べ方は 2 マスの入れ替えで前の札と重ならないようにする。
- 結果（コード 5 種で確かめた）：同じカード 0 組・同じ位置に同じ出来事 0 組・同じ列に 3 個以上同じ出来事 0 組・2 枚で重なる出来事は平均 4.4 個／最大 7 個（24 個中）。
- どの列もやさしいが 1 個以上・むずかしいは 2 個まで（どの列にもそろう見込みがある）。
- 同じゲームコードなら、どの端末でも同じ 16 枚になる（乱数の種がコード）。

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | 画面（幹事・各自のカード・印刷） |
| bingo-core.js | 画面に依存しない関数（出来事の一覧・カードの作成・違いの点検・ビンゴの判定・番号の抽選） |
| bingo-sync.js | Firestore への記録（参加の抽選・印・参加状況） |
| firebase-config.js | Firebase の接続設定（GolfMatch と同じ） |
| firestore.rules | Firestore のルール全文（GolfMatch＋bingo） |
| test.html | bingo-core の試験（64 件） |

URL：幹事 `index.html#g=コード&admin`、参加 `index.html#g=コード`、各自のカード `index.html#g=コード&p=番号`、印刷の見本 `index.html#g=コード&print`。名前は URL に入れない。
