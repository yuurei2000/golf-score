# AIゴルフコーチ（Web 版）

コーチが生徒さんに書いたレッスンのホワイトボード 54 回（2025/10〜2026/10）の書き起こしと分析をもとに、ゴルフの悩みに「板の形」（☆テーマ → ↳ 動き → ‖ クラブ → ‖ 球 → Q なぜ）で答える AI のコーチ。コーチ本人ではない。公開用に名前は伏せてある。

## 使い方

- **API キーなし**：「板から探す」。悩みの言葉（ダフる・引っかけ・パター など）に合う板の処方とドリルを出す。
- **API キーあり**（設定で入れる）：Claude（既定は Claude Opus 5.5）が、54 回の板と教えの要点を読んだうえで答える。キーはその端末のブラウザ（localStorage）にだけ保存し、Anthropic の API へ直接送る。料金はキーの持ち主にかかる。
- 「板の一覧」で 54 回の板の書き起こしを読める（読みに自信のない字は〔?〕）。

## ファイル

| ファイル | 中身 |
|---|---|
| index.html | 画面（相談・板の一覧・設定） |
| coach-core.js | 画面に依存しない関数（system の組み立て・要求・板から探す・板の表示） |
| coach-data.js | 板 54 回と教えの要点（自動生成。手で直さない） |
| store.js | この端末への保存 |
| test.html | coach-core の試験 |

Claude の呼び出しは公式 SDK `@anthropic-ai/sdk@1.8.0`（jsDelivr の ESM）を `dangerouslyAllowBrowser: true` で使う。
